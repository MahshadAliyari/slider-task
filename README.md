# 🖼️ Image Slider

A responsive image slider built with **HTML, CSS, and JavaScript**.

The project displays multiple images with navigation buttons, automatic sliding, and clickable indicators.

---

## ✨ Features

* Mobile-first responsive design
* Display multiple images
* Previous image button
* Next image button
* Automatic image changing (Auto Play)
* Image indicators (Dots)
* Active indicator for the current image
* Clickable indicators for direct navigation
* Infinite looping between images
* Modern and responsive UI

---

## 🛠️ Technologies

* **HTML**
* **CSS**
* **JavaScript**
